# Instagram followers Mini App

A web page that opens inside Telegram. It reads each person's Instagram export on their own device, and saves the lists to their own Telegram account. There's no server, so nobody's computer has to stay on.

## Put it online

1. Create a free account at [github.com](https://github.com).
2. Create a new public repository named `instagram-followers`.
3. Choose **uploading an existing file** and upload the files in this folder: `index.html`, `app.js`, `export.js`, `storage.js`, `zip.js` and `style.css`. Upload the files themselves, not the folder.
4. In the repository, go to **Settings > Pages**. Under **Branch**, choose **main** and **/ (root)**, then save.
5. Wait a minute or two, then copy the address GitHub shows: `https://YOUR-USERNAME.github.io/instagram-followers/`.

## Connect it to the bot

1. In @BotFather, send `/mybots`, choose your bot, then go to **Bot Settings > Configure Mini App**.
2. Enable the Mini App and paste the GitHub address.
3. Go back to **Bot Settings > Menu Button**, and set the same address, with the button text `Open`.

Open the bot and tap **Open**.

To change the page later, upload the changed files to the same repository.
